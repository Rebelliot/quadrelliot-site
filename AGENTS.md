# Quadrelliot Website

This is the public website for Quadrelliot, a commercial drone inspection business.

## General rules

- Preserve the established Quadrelliot visual identity unless explicitly asked for a redesign.
- The existing design language is cream, white, slate and orange.
- Keep the site professional, modern, minimal and commercially credible.
- Do not invent services, prices, qualifications, statistics, clients, certifications or claims.
- Do not rewrite existing copy unless explicitly asked.
- Do not remove existing functionality unless explicitly asked.
- Prefer small, deliberate changes over unnecessary rewrites or refactors.

## Images

- Prefer real supplied Quadrelliot photography over stock imagery.
- Keep photographs sharp and appropriately cropped.
- Use responsive image layouts that work on desktop, tablet and mobile.
- Avoid stretching or distorting photographs.
- Use appropriate alt text.
- Optimise image delivery where appropriate using Next.js image features.
- Do not apply heavy filters or effects to supplied photographs.

## Responsive design

- Every visual change must be checked at desktop and mobile widths.
- Do not allow desktop improvements to damage the mobile layout.
- Maintain sensible spacing and readable typography at all viewport sizes.

## Development

- Run lint after meaningful changes.
- Run a production build before considering a substantial change complete.
- Where practical, run the development server and visually inspect changes.
- Do not unnecessarily change working code.
- Do not perform broad refactors while implementing an unrelated visual change.

## Git and deployment

- Never push, deploy, merge into main, or create a pull request unless explicitly instructed.
- Never assume that pushing is safe because the production deployment mechanism may be connected directly to GitHub.
- Show me what has changed before publishing anything.
